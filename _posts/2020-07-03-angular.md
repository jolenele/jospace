Đánh dấu sự trở lại sau một thời gian bỏ ngõ, mình sẽ bắt đầu với Angular, một framework mà mình khá thích.

Angular là một JavaScript Framework được dùng để develop web applications. Có thể bạn đã từng nghe tới MEAN tech stack, gồm M - MongoDB cho NoSQL Database, E - ExpressJS cho Back-end, A - Angular cho Front-end, và N - NodeJS cho Environment. Thật sự mà nói vì một vài lí do cá nhân mà mình dành một tình cảm đặc biệt cho Angular, dù không thể phủ nhận được React (MERN stack)đang dần chiếm ưu thế hơn trong thị trường.

Để tạo một web app Angular, bạn cần phải cài đặt Angular CLI với command line:

_npm install -g @angular/cli_

Sau đấy chỉ cần dùng lệnh:

_ng new your-app-name_

là hô biến, bạn đã có ngay một web app theo default template của Angular. Về điểm setup thì phải nói Angular cực kì đơn giản, và nhanh chóng.

Framework này dùng để phát triển SPA (a single-page application), là trang web chỉ gói gọn trong một trang. Trước kia với những cách dev web app mà chúng ta vẫn quen thuộc dùng như Java hay .NET, một web app thường mỗi chức năng/ứng dụng sẽ được navigate tới một trang khác như, trang chủ, trang chọn hàng, trang thanh toán, etc., mỗi lần mở là đi như bạo hành cái web browser. Thì bây giờ đây, loài người đã đơn giản hoá nó bằng SPA, nghĩa là không cần biết bạn đi đâu trong cái app này, nó vẫn chỉ gói gọn trong một trang.

Quay trở lại Angular, để có thể gói gọn mọi thứ trong một web page, Angular sử dụng components và routers. Nghĩa là mỗi phần sẽ là một component riêng biệt, và dùng router để navigate tới component đó.

Lệnh để tạo một component là **ng generate component component-name**. Muốn connect component mới tạo, chỉ cần thêm path vào router trong app-routing.module.ts. Muốn thêm component đấy vào app, chỉ cần thêm selector tag của component đó vào app.component.html file, đơn giản như đang giỡn. Với mình nó cứ như kiểu chơi lego, bạn sẽ lắp từng part nhỏ vào để tạo thành một model lớn, muốn thêm gì cứ lắp nó vào.

Nói về component thì không thể không nhắc tới service. Cứ tưởng tượng bạn làm một web app có tới 50 components (như những web cho big banks), và có những feature chắc chắn bạn không muốn phải lặp lại 50 lần như validate user input hay fetching data từ data source. Để giải quyết vấn đề đó, Angular cho ra đời Service, nói nôm na nó là một class chứa những function hay feature hay static value mà web app cần để tăng reusability cho code của bạn. Thông qua _dependency injection_, bạn có thể inject service bạn cần vào components và sử dụng nó.

Về front-end design, bạn sẽ vẫn gặp lại những người bạn HTML/CSS thân thương. Tuy nhiên, ở những bước đầu tiên để tạo web app, bạn sẽ thấy trong terminal Angular cho bạn những option style sheet format khác ngoài CSS như SCSS, SASS, LESS hay Stylus. Ví dụ SCSS thì powerful hơn CSS hay SASS sẽ dễ dàng cho maintenance hơn chẳng hạn. Nếu có dịp mình có thể sẽ nói về những format này sau.

Một điểm highlight của Angular mà mình muốn điểm đến là data binding gồm 3 loại cơ bản Interpolation (binding một chiều từ data source tới view), Event (binding một chiều từ view tới data source, và Two-way (binding hai chiều giữa view và data source). Data binding cho phép bạn handle data và thấy kết quả in real-time basic. Template-driven Form là một ví dụ cực điển hình.

Hmmm, nói chung mình đã cover kha khá những điểm cơ bản về Angular rồi. Thật ra đã lâu rồi chưa viết Angular nên tạm thời mình không nhớ quá nhiều chi tiết về những điểm tech nhỏ. Ban đầu lúc mới tiếp xúc, mình thấy nó rối nhoằm một nùi, nhưng khi hiểu logic và data flow của nó rồi thì mình lại thấy khá thích. Một điểm cộng nữa cho Angular là nếu bạn muốn migrate web app sang mobile app, bạn hoàn toàn có những lựa chọn như NativeScipt hay ReactNative khi đều viết bằng JavaScipt, chạy trên NodeJS environment và có thể dùng cả SQL, SQLite hay NoSQL. Setup CI/CD pipline một MEAN stack cũng khá là dễ dàng. Nói đến đây mình thấy JavaScript nó powerful ghê gớm haha.

Sau khi đọc bài viết này bạn cảm thấy bị kích thích và muốn tìm hiểu về Angular, mình recommend bạn vào documents và làm theo tutorials của nó, phần giải thích cực kì chi tiết, đơn giản và hay ho. Mình sẽ để link ở dưới phần reference. You will master Angular before you know it ;)
